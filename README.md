Виконав: Побережнюк Юрій Вікторович, група 241б.

**Варіант:** завдання 1 — спільне для всіх, завдання 2 — №11

## Завдання

| № | Головний клас | Що робить |
|---|---|---|
| 1 | `task1.Main` | Записи `Money`/`Fraction` з файлів у `ArrayList`, сортування (Comparable, Comparator), запис у `all_sorted.txt` |
| 2 | `task2.Main` | Рядки з файлу в `ArrayList` і сортування `Collections.sort()` (вхід: `data/poems.txt`) |

Вхідні файли лежать у папці `data`; конфігурації запуску в IDEA вже запускають програми з неї.

## Як запустити

**IntelliJ IDEA:** File → Open → папка `Laba_5_Java`. Якщо IDEA попросить JDK, натисни *Setup SDK* → *Download JDK* (підійде будь-яка версія від 8).
Для кожного завдання вже є конфігурація запуску — обери її у списку вгорі праворуч і натисни ▶.

**Командний рядок** (з кореня проєкту):

```
javac -encoding UTF-8 -d out src/records/*.java src/task1/*.java src/task2/*.java
cd data
java -cp ../out task1.Main
```

Код сумісний з Java 8 і новішими.
